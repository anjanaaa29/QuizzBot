# EduSupport Chatbot

💬 **EduSupport** is an AI-powered career and study assistant chatbot designed to help students and professionals with questions related to jobs, study strategies, interview preparation, resume writing, and career guidance. The bot uses Groq’s LLM API to provide real-time, contextual answers.

---

## 🌟 Features

- Conversational AI interface with styled chat bubbles.
- Handles queries related to:
  - Job search strategies
  - Study methods and educational topics
  - Interview preparation
  - Resume and cover letter writing
  - Career development and advancement
  - Technical skills for specific roles
  - Networking and industry insights
- Off-topic detection: the bot politely redirects unrelated queries.
- Restart chat button to clear the conversation while retaining system context.
- Responsive chat UI with user and bot avatars.

---

## 🛠️ Requirements

- Python 3.10+
- Streamlit
- Groq SDK (`pip install groq`)
- python-dotenv (`pip install python-dotenv`)
- Optional: Font Awesome for avatars (via CDN)
